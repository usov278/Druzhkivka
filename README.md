## 📖 О проекте

**«Дружковка»** — учебный многостраничный веб-сайт, посвящённый истории, инфраструктуре, культуре и современной жизни города.

Проект разработан в рамках лабораторной работы по веб-разработке.

Главная задача проекта — создать полноценный адаптивный сайт с использованием **HTML5, CSS3 и JavaScript**, применяя семантическую разметку, современные возможности CSS и интерактивные элементы.

---

## 🗂️ Структура сайта

Сайт состоит из шести основных страниц:

| Страница                    | Описание                                                                      |
| --------------------------- | ----------------------------------------------------------------------------- |
| 🏠 **Главная**              | Общая информация о Дружковке, фотографии и городские события                  |
| 👨‍💻 **Разработчик**       | Информация об авторе проекта и его навыках                                    |
| 📜 **История города**       | Основные исторические события и этапы развития Дружковки                      |
| 🏗️ **Инфраструктура**      | География, административное устройство, транспорт и социальная инфраструктура |
| 🎭 **Культура и искусство** | Музеи, театры, библиотеки и культурное наследие города                        |
| ✉️ **Обратная связь**       | Форма для отправки вопросов, предложений и сообщений                          |

## ✨ Возможности

### 🌆 Информация о городе

* описание Дружковки;
* историческая справка;
* информация о географическом положении;
* сведения об административном устройстве;
* транспортная инфраструктура;
* социальные объекты;
* культурное наследие.

### 🖼️ Фотогалерея

На главной странице размещена адаптивная галерея фотографий города.

Изображения:

* автоматически подстраиваются под размер экрана;
* имеют альтернативное описание;
* используют `loading="lazy"` для оптимизации загрузки.

### 📊 Информация о разработчике

На странице разработчика представлены:

* фотография;
* краткая биография;
* направление обучения;
* навыки программирования;
* визуальные индикаторы уровня владения технологиями.

### 📜 История

Исторические события представлены в виде структурированной таблицы с указанием:

* даты;
* события;
* его значения для развития города.

### 🗺️ Карта

На странице инфраструктуры размещена интерактивная карта города с использованием Google Maps.

### ✉️ Форма обратной связи

Форма содержит:

* имя;
* адрес электронной почты;
* тему обращения;
* текст сообщения;
* согласие на обработку данных;
* автоматическую проверку введённых данных;
* счётчик слов;
* счётчик символов.

Проверка формы реализована с использованием **HTML5 Validation API и JavaScript**.

> ℹ️ В текущей версии форма не отправляет сообщения на реальную электронную почту. После успешной проверки отображается сообщение о подготовке обращения к отправке.

* дополнительной проверки электронной почты;
* отображения результата отправки;
* управления интерактивными элементами страницы.

## 🚀 Запуск проекта

Для запуска проекта не требуется установка дополнительных зависимостей.

### Способ 1 — открыть напрямую

Открой файл:

```text
index.html
```

в любом современном браузере.

### Способ 2 — через PhpStorm

1. Открыть проект в **PhpStorm**.
2. Открыть `index.html`.
3. Нажать **Open in Browser**.
4. Выбрать предпочитаемый браузер.
